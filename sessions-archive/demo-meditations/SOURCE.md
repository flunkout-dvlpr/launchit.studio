# Source

The real project lives in its own separate, private repository, not inside
this one and not published publicly, so there's no link to point to here.

This folder has two files:

- **`CLAUDE.md`** — the primary brief, covering all four phases of the
  actual finished project (dataset, backend, frontend, deployment). This is
  the file someone should download to kick off the whole project themselves,
  and it's the one referenced from the site's download link. It was written
  2026-07-30 by working backward from the real, shipped code, not from the
  live project's own `CLAUDE.md` file (see below for why).
- **`CLAUDE-phase1-original.md`** — a verbatim copy of the live project's
  actual `CLAUDE.md`, archived 2026-07-30. It's the real brief that kicked
  off phase one (the dataset pipeline) and is what
  `demo-1-text-to-dataset.md` on the site is written from. It was never
  updated past phase one, even though the project went on to also build a
  Quasar frontend and an SMS-delivery backend, so it still describes
  delivery as "intentionally open." Kept here as an accurate historical
  record, not fixed, since that's genuinely what the file said at the time.
