# Prep guide — building a social media content manager with Claude
**Session:** [Date] · Impact Hub Houston at The Ion
**Read time:** ~3 minutes

## What we're building
A small business's real workflow for going from "I need to post something" to a scheduled, on-brand post — using Claude to write captions, brief out visual assets, and hand off to a scheduling tool. We're walking through this live with the business owner who actually uses it.

## The business case
[Business name / "a Houston-based ___"] currently spends [X hours/week] on social content: brainstorming captions, briefing a designer or generating assets, and manually scheduling posts across platforms. We'll show the current process, then the Claude-assisted version side by side.

## Before you arrive
You don't need any technical background. You do need:
- A free or paid [Claude.ai](https://claude.ai) account, logged in
- One real example from your own business: a product, offer, or announcement you'd normally post about (even a rough idea is fine)
- 10 minutes, sometime before the session, to try the mini exercise below

## Try it yourself (optional, ~10 min)
Open a new chat with Claude and paste this, filling in your own business:

```
I run a [type of business] and want to post about [what you're
promoting]. My brand voice is [3 words, e.g. "warm, direct, no jargon"].
Write 3 caption options for Instagram, each under 150 characters,
with one relevant hashtag set.
```

Bring whatever it gives you — good or bad — we'll build on real attempts in the room, not a blank slate.

## What we'll walk through live
1. **Caption generation** — turning a rough idea into on-brand copy, and iterating on tone
2. **Asset briefing** — using the caption to generate a clear brief for an image/graphic (design tool of choice)
3. **Handoff to scheduling** — organizing the above into a postable, dated queue

Each step will use a prompt you can copy directly — no need to write anything from scratch during the session.

## After the session
A recap + the full prompt set will be shared back through Impact Hub Houston's channels, along with the call for the next cycle's use case submission — if you've got a business problem you'd like built out next, that's where to submit it.
